# Batalla LOTR - El Señor de los Anillos

## Descripción del Proyecto

Simulador de batallas inspirado en El Señor de los Anillos. 
Este proyecto permite crear ejércitos de héroes y bestias, 
personalizarlos y simular combates épicos.

## Características

* Sistema de combate por turnos
* Habilidades especiales para cada tipo de personaje
* Interfaz gráfica con Swing
* Sistema de música de fondo
* Mapas intercambiables temáticos
* Animación de texto en tiempo real

## Tipos de Personajes

### Héroes
* **Elfo**: Bonus contra Orcos
* **Humano**: Valiente ante enemigos fuertes
* **Hobbit**: Miedo a los Trasgos
* **Ent**: Aplasta enemigos débiles
* **Dúnedain**: Sobrevive con 1 HP una vez

### Bestias
* **Orco**: Fuerza bruta
* **Trasgo**: Estándar
* **Uruk-Hai**: Consume vida para atacar
* **Nazgûl**: Inflige miedo
* **Troll**: Armadura resistente

## Tecnologías Utilizadas

* Java 11
* Swing (interfaz gráfica)
* Maven (gestión del proyecto)
* Java Sound API (música)
